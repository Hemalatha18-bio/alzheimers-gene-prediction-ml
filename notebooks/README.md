# Notebooks

This directory is reserved for optional exploratory notebooks associated with the public demonstration.

The authoritative, reproducible implementation for this repository is maintained in the Python scripts under `src/`, with automated tests under `tests/` and workflow orchestration under `workflow/`.

If notebooks are added later, they should:

- use only public or example data suitable for distribution;
- avoid duplicating unsupported quantitative claims from broader project work;
- clearly distinguish exploratory analysis from validated results;
- record required dependencies and random seeds where applicable; and
- export important reusable logic into tested Python modules rather than leaving core analysis only in notebook cells.

At present, no notebook is required to reproduce the included public demo.
